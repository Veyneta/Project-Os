# CPU Scheduling Simulator

โปรเจกต์นี้เป็นเว็บแอปพลิเคชันจำลองการจัดตารางการทำงานของ CPU
เพื่อเปรียบเทียบอัลกอริทึม FCFS, SJF แบบ Non-preemptive และ Round Robin (RR)

## ความสามารถของโปรแกรม

-   เพิ่มและลบ Process
-   กำหนด Process ID, Arrival Time (AT) และ Burst Time (BT)
-   เลือกอัลกอริทึมสำหรับจัดตารางการทำงาน
-   กำหนด Time Quantum เมื่อเลือก Round Robin
-   แสดง ST, CT, TAT และ WT ของแต่ละ Process
-   แสดงค่าเฉลี่ย Waiting Time (AVG WT)
-   แสดงลำดับการทำงานของ Process
-   แจ้งข้อผิดพลาดเมื่อกรอกข้อมูลไม่ถูกต้อง

## อัลกอริทึมที่รองรับ

### 1. First Come, First Served (FCFS)

ทำงานตามลำดับที่ Process เข้ามา โดยผู้ที่มาก่อนได้ทำงานก่อน

### 2. Shortest Job First (SJF --- Non-preemptive)

เลือก Process ที่มี Burst Time น้อยที่สุดจาก Process ที่มาถึงแล้ว
เมื่อเริ่มทำงานจะทำต่อจนเสร็จก่อนเลือก Process ถัดไป

### 3. Round Robin (RR)

ให้แต่ละ Process ใช้ CPU ตามช่วงเวลาที่กำหนด เรียกว่า Time Quantum
หากยังทำงานไม่เสร็จเมื่อหมด Quantum จะถูกนำกลับไปต่อท้ายคิว

## ค่าที่ใช้ในการคำนวณ

  ค่า                      ความหมาย                    สูตร
  ----------------------- --------------------------- --------------------------
  AT (Arrival Time)       เวลาที่ Process มาถึง          กำหนดจากข้อมูลนำเข้า
  BT (Burst Time)         เวลาที่ Process ต้องใช้ CPU     กำหนดจากข้อมูลนำเข้า
  ST (Start Time)         เวลาเริ่มทำงาน                เวลาที่ Process เริ่มใช้ CPU
  CT (Completion Time)    เวลาที่ทำงานเสร็จ              เวลาสิ้นสุดการทำงาน
  TAT (Turnaround Time)   เวลาตั้งแต่มาถึงจนทำงานเสร็จ     `TAT = CT - AT`
  WT (Waiting Time)       เวลารอคิวรวม                 `WT = TAT - BT`
  AVG WT                  ค่าเฉลี่ยเวลารอของทุก Process   ผลรวม WT ÷ จำนวน Process

## โครงสร้างไฟล์

-   `index.html` --- โครงสร้างหน้าเว็บ ช่องกรอกข้อมูล ปุ่ม และตารางผลลัพธ์
-   `styles.css` --- รูปแบบหน้าตาและการจัดวางหน้าเว็บ
-   `app.js` --- รับข้อมูลจากผู้ใช้ เรียกใช้อัลกอริทึม และแสดงผลบนหน้าเว็บ
-   `scheduler.js` --- คำนวณ FCFS, SJF, Round Robin และค่า ST, CT, TAT,
    WT, AVG WT
-   `scheduler.test.js` --- ทดสอบผลลัพธ์ของอัลกอริทึมและกรณีข้อมูลไม่ถูกต้อง

## วิธีเปิดใช้งาน

1.  ดาวน์โหลดหรือ Clone โปรเจกต์ลงในเครื่อง
2.  ตรวจสอบว่า `index.html`, `styles.css`, `app.js` และ `scheduler.js`
    อยู่ในโฟลเดอร์เดียวกัน
3.  เปิด `index.html` ด้วยเว็บเบราว์เซอร์
4.  เพิ่ม Process และกรอก AT กับ BT
5.  เลือกอัลกอริทึมที่ต้องการ หากเลือก RR ให้กำหนด Time Quantum ด้วย
6.  กดปุ่มคำนวณเพื่อดูผลลัพธ์

## วิธีรันทดสอบ

ต้องติดตั้ง Node.js ก่อน จากนั้นเปิด Terminal หรือ Command Prompt
ในโฟลเดอร์โปรเจกต์ แล้วรัน:

``` bash
node scheduler.test.js
```

หากผ่านการทดสอบ จะแสดงข้อความ:

``` text
scheduler tests passed
```

ชุดทดสอบตรวจสอบผลลัพธ์ของอัลกอริทึม รวมถึงกรณีข้อมูลไม่ถูกต้อง เช่น ไม่มี Process, Burst
Time ไม่ใช่จำนวนเต็มบวก และ Time Quantum ไม่ใช่จำนวนเต็มบวก

## หมายเหตุ

-   Arrival Time ต้องเป็นตัวเลขตั้งแต่ 0 ขึ้นไป
-   Burst Time ต้องเป็นจำนวนเต็มบวก
-   Time Quantum ของ Round Robin ต้องเป็นจำนวนเต็มบวก
-   ชื่อไฟล์ที่ใช้รันทดสอบต้องตรงกับชื่อไฟล์จริงในโปรเจกต์
